## The line

> My agent called my typo brilliant, invented an API to fix it, called it twice, then apologized to the 404 for the trouble.

122 characters, inside the 140-character limit.

## How it works

`main.py` (Python 3 standard library only) writes that single line to `/output/entry.txt`. Nothing else, no network, no secrets.

Run it:

```sh
python3 main.py
```
